# 示例数据和缺失资源

| 文件 | 来源、格式与字段 | 放置位置 |
| --- | --- | --- |
| `KG.txt` | 提交者本地实验材料；每行 `[主体, 关系, 客体]`，内容为家庭成员、旅行偏好、出差会议与证件需求的示例知识图谱 | `data/examples/KG.txt` |
| `Database_kg(1).txt` | 提交者本地草稿材料；每行数据库结构三元组，含 students、grades、health 的字段、类型与主外键关系；不含实际学生记录 | `data/examples/Database_kg(1).txt` |

版本标识为此次提供文件的 SHA-256，见论文目录内 `SOURCE_MANIFEST.json`；原始材料未标记发布日期。两份示例随本目录提供，无需提取码或下载外部数据，也没有独立网盘入口。它们不是完整训练/验证/测试集，不据此虚构样本分区。示例本身只包含关系描述和数据库 schema，未在本目录提供真实用户账号或业务数据库。

如需单独获取固定来源版本，可在本 PR 合并后的论文目录下载；归档前的本地材料是 `RUN_code.ipynb` 实际采用的 KG 来源。离线示例直接读取随附的 `KG.txt`，无预处理要求。

未随材料提供：完整网页任务清单、任务成功标签、统一数据划分、完整页面快照、结构化技能库/用户存储、自定义 `metagpt.management` 实现。以上没有可核实的公开下载地址；缺少它们时不能端到端运行原 Agent 或重算成功率。

运行主原型需要自行提供有权限的模型 API；不使用本地预训练模型权重或分词器检查点。历史模型名称见主 README，当前访问权限和可用性未验证。草稿中的数据库任务也未附完整数据库，不能用示例 schema 代替实际数据。
